Tasks
1.
Create a simple web form named RegisterUser.jsp for new users to sign up with fields: username, email, and password. On submit, post the data to a RegisterUserServlet that saves the user info into a database table called users.
2.
Build a LoginServlet that authenticates users by checking their username and password against the users table in the database, then redirects to a Home.jsp page if successful.<br><br><em><strong>Hint:</strong> Use JDBC to query the database and HttpSession to store login state.</em>
3.
Design an EventPost.jsp page where a logged-in user can submit a new event with title, date, and description. The form should POST to an EventPostServlet that inserts the event into an events table in your database.
4.
Display a dynamic list of all events on EventsList.jsp by fetching event data from the events table in your database and passing it from an EventListServlet to the JSP using request attributes.<br><br><em><strong>Constraint:</strong> Use a JavaBean class named Event to represent each event in your list.</em>
5.
Refactor your servlets and JSPs to follow the MVC pattern clearly: controllers (Servlets), models (JavaBeans), and views (JSPs). Briefly comment each file to indicate its role in MVC.

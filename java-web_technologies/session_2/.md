Tasks
1.
Set up Apache Tomcat on your system, create a new Dynamic Web Project in Eclipse (or IntelliJ), and configure it to run on Tomcat by displaying a simple HTML page at http://localhost:8080/.
2.
Create a Java servlet named WelcomeUserServlet that displays 'Welcome, User!' in the browser when accessed via /welcomeuser.
3.
Override the init(), service(), and destroy() methods in your WelcomeUserServlet and log a message to the console each time one of these methods is called.<br><br><em><strong>Hint:</strong> Use System.out.println() inside each method to print which lifecycle method is running.</em>
4.
Edit your project's web.xml deployment descriptor to map the WelcomeUserServlet to the URL pattern /welcomeuser and set an init-param called 'appName' with value 'MyWebApp'. Display the value of 'appName' in your servlet's response.
5.
Imagine you want to create a servlet for a Zomato-style food review app. Write the <servlet> and <servlet-mapping> entries you would add to web.xml to register a ReviewServlet at the URL pattern /addreview.<br><br><em><strong>Constraint:</strong> Only write the required XML snippet for web.xml, not the Java code.</em

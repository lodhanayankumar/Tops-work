Tasks
1.
Set up a Java Servlet named ProductListServlet that connects to a MySQL database using JDBC and retrieves all records from a 'products' table (id, name, price).
2.
Create a JSP page called products.jsp that receives a list of Product objects from the servlet and displays them in a table with columns for ID, Name, and Price.
3.
Modify your ProductListServlet to handle SQL exceptions and display a user-friendly error message on the JSP page if the database connection fails.<br><br><em><strong>Hint:</strong> Use request.setAttribute to pass error messages to the JSP.</em>
4.
Add a search feature to your ProductListServlet so that if a 'name' parameter is sent in the request, only products whose names contain that string (case-insensitive) are fetched and displayed in the JSP table.<br><br><em><strong>Hint:</strong> Use a SQL LIKE query with wildcards for partial matching.</em>

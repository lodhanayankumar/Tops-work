Ans.
 GitHub Copilot was used to generate the basic upload and download methods by providing method signatures and comments 
 describing the required logic. I modified the generated code to support MP3 files, use the application's uploads folder, 
 validate filenames, set the correct MP3 content type, and stream downloaded files using a buffer. I also adapted the 
 code to the Jakarta Servlet API and the requirements of this project.

Changes I Made to the Copilot-Generated Code
1. Restricted uploads to MP3 files by checking .mp3 extension.
2. Added the uploads folder and automatically created it when it does not exist.
3. Used MultipartConfig so the servlet can receive multipart file uploads.
4. Added Content-Disposition: attachment in the download servlet so the browser downloads the MP3.
5. Used an 8192-byte buffer to stream the file instead of loading the complete MP3 into memory.
6. Adapted the code to our project by using jakarta.servlet and servlet URLs /uploadSong55 and /downloadSong55.

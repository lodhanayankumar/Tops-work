Tasks
1.
Write a Java function generateRandomOtp() that returns a 6-digit numeric OTP as a String each time it is called.
2.
Simulate a Zomato-style signup: when a user enters their email, generate an OTP using generateRandomOtp(), store it in a temporary HashMap with the email as key, and print the OTP to the console (simulating email delivery).
3.
Create a validateOtp(email, inputOtp) method that checks if the inputOtp matches the OTP stored for that email and returns true or false. If the OTP is correct, remove it from the HashMap.
4.
Extend your OTP logic to add expiry: store the OTP creation time along with the OTP, and make validateOtp() return false if more than 2 minutes have passed since OTP generation.<br><br><em><strong>Hint:</strong> Use System.currentTimeMillis() to track time and compare.</em>
5.
Use ChatGPT or LangChain4J to generate Java code for an OTP generator function, then compare its output to your own generateRandomOtp() implementation and list two differences.

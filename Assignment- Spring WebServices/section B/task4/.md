Task 4: AI Meal Recommendation Endpoint
Build a Spring Boot REST endpoint that calls the OpenAI Chat Completions API and returns an
AI-generated meal recommendation based on a user-supplied dietary preference.
Create a POST /recommend endpoint that accepts a JSON request body with a single field
preference (e.g., 'vegetarian', 'high protein').
Use Java's HttpClient to send a POST request to https://api.openai.com/v1/chat/completions
with the correct JSON body (model, messages array) and Authorization: Bearer header.
Parse the API response using Jackson's ObjectMapper and extract the assistant reply from
choices[0].message.content.
Return the extracted recommendation as a JSON field in the response body; handle API failure
by returning HTTP 502 with a descriptive error message.

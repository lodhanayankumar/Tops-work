Task 2: Order Persistence with Spring Data JPA
Build a Spring Data JPA entity and repository layer to persist customer orders in a relational
database.
Create an Order entity annotated with @Entity, @Table, @Id, @GeneratedValue, and @Column
for the fields: id, customerName, itemName, quantity, and totalAmount.
Create an OrderRepository interface that extends CrudRepository<Order, Long>.
Add a derived query method findByCustomerName(String name) to the repository interface;
no implementation is required.
Write a CommandLineRunner bean that saves two sample orders on startup, then calls
findAll() and findByCustomerName() and prints the results to the console

Task 3: Delivery Status Fetcher using HttpClient and Jackson
Write a standalone Java program that calls a public REST API, parses the JSON response using
Jackson, and displays the extracted fields.
Use Java's built-in HttpClient (java.net.http) to send a GET request to
https://jsonplaceholder.typicode.com/todos/1.
Create a Todo POJO with fields userId, id, title, and completed matching the API response
structure.
Use Jackson's ObjectMapper.readValue() to deserialise the JSON response string into a Todo
object.
Print each field of the parsed Todo object to the console in a clearly labelled, formatted output.

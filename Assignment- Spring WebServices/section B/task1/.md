Task 1: Food Menu REST Controller
Build a Spring Boot REST controller that exposes read and write endpoints for a food delivery
menu.
Annotate the class with @RestController and map it to the base path /menu.
Implement GET /menu to return a hardcoded list of at least three MenuItem objects (fields: id,
name, price) serialised as JSON.
Implement GET /menu/{id} using @PathVariable to return a specific menu item matched by
its ID, or a 404 status if not found.
Implement POST /menu using @RequestBody to accept a new MenuItem and add it to the
in-memory list, returning the saved item with HTTP 201.

3. Explain in your own words, with 3-4 sentences, how Inversion of Control (IoC) and Dependency Injection (DI) help make your
   PlaylistService more modular and easier to test. Give a concrete example from your code.
   Ans.
        Inversion of Control (IoC) means that Spring creates and manages objects instead of me creating them manually. Dependency
        Injection (DI) allows Spring to provide the SongRepository object to PlaylistService through its constructor. This makes my
        code more modular because I can change the repository without changing the main playlist logic. For example, I can inject a
        different repository with test songs to test PlaylistService without connecting to a real database.

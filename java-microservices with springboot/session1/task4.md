3. List 4 advantages of using microservices over a monolithic architecture for a movie ticket booking app (like BookMyShow), 
   and give a one-line example for each advantage.
Ans.
    4 Advantages of Microservices over Monolithic Architecture
    No.	Advantage	One-line example (Movie Ticket Booking App)
    1.	Independent Deployment -- The Payment Service can be updated without redeploying the entire movie booking application.
    2.	Scalability	-- During a blockbuster movie release, the Booking Service can be scaled up to handle more users.
    3.	Fault Isolation --	If the Notification Service fails to send SMS messages, users can still book movie tickets.
    4.	Technology Flexibility --	The Recommendation Service can use Python AI, while the Booking Service uses Java Spring Boot.
